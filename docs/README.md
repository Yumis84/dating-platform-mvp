# Документация проекта

В этой директории находятся дополнительные документы по архитектуре, правила разработки и техническое задание (ТЗ).

Структура:
- architecture/ — диаграммы и пояснения архитектуры
- rules/ — правила разработки и согласованные практики
- tz/ — техническое задание и требования к MVP
