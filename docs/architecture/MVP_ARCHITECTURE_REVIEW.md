2) Что было проверено (автоматически)
-------------------------------------
- Репозиторий: используйте git ls-tree / find для просмотра корневой структуры.
- Каталог миграций: database/migrations/ — перечислите файлы, проверьте, что они отслеживаются в Git и получите blob SHA для каждой записи.

3) Методология проверки — общие указания
---------------------------------------
- Не делать выводов об отсутствии файлов без проверки дерева репозитория и списка миграций.
- Проверка должна включать:
  - просмотр каталога database/migrations/
  - подтверждение последовательности нумерации и наличия файлов 001–007
  - проверку, что миграции применялись в нужном порядке (если есть миграционные логи/CI или схема контрольных точек)
