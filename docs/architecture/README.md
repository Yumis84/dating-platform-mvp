# Архитектура

Здесь будут размещены диаграммы и пояснения архитектуры системы Dating Platform MVP v1.0.

Кратко:
- Telegram Bot — отвечает за приём сообщений/заявок и взаимодействие с пользователем через чат.
- Telegram WebApp — фронтенд для расширенного интерфейса внутри Telegram.
- n8n — оркестратор рабочих процессов (интеграции, автопостинг, обработка медиа и т.д.).
- PostgreSQL — основная реляционная база данных (проектируется, но БД пока не создаётся).
- Google Sheets — лёгкое внешнее хранилище/спreadsheets для MVP (импорт/экспорт данных).
- AI Agent — помощник для автоматизации, рекомендаций и обработки контента.

Подробнее — дополнять по мере прогресса в этой папке.
