# AI Agent Documentation Index

## Назначение

Эта папка содержит постоянный контекст для AI-агентов, которые продолжают работу над репозиторием в новых сессиях или аккаунтах.

## Перед началом работы агент должен прочитать:

1. `docs/AI_AGENT_CONTEXT.md` — правила работы, архитектурный контекст, ограничения и формат взаимодействия.
2. `docs/AI_AGENT_HISTORY.md` — история решений, выполненных этапов и важных договорённостей.

## Обязательные правила

- Не менять SQL-мigrations, n8n workflows, Docker/infrastructure или application code без отдельного согласования.
- Использовать документацию как source of truth.
- Перед большими изменениями проверять связанные документы и сохранять обратную совместимость.
- После каждого этапа выдавать отчёт: что изменено, SHA коммита, затронутые файлы, риски.

## Текущий процесс

Работа продолжается через последовательные AI-сессии. Каждый новый агент должен сначала изучить контекст и историю, затем проверить актуальное состояние репозитория.
