# ТЗ №2 — Создание анкеты девушки через Telegram и AI Agent

## Цель
Женщина после регистрации создаёт анкету через бота с помощью AI Agent: данные о себе, фото, цены, места встречи.

## Технологии
n8n · Telegram Bot API · AI Agent · Google Sheets · Telegram file_id

## Листы
Анкеты · Фотографии · Цены · Места встречи

## Логика AI
Свободный ввод («Меня зовут Анна, мне 38, Калининград») → AI выделяет поля. Недостаточно данных → уточняющие вопросы.

Последовательность: имя → возраст → город → район → рост → вес → грудь → описание → фото → цены → места.

## Фото
Только file_id, не скачивать на сервер.

## Перед публикацией
Проверка обязательных полей. Статус: «На модерации».

## Критерии
✅ анкета создаётся  ✅ AI собирает данные  ✅ file_id  ✅ запись в Sheets  ✅ статус  ✅ ошибки не ломают workflow
