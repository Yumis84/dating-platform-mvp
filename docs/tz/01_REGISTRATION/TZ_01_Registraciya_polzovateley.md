# ТЗ №1 — Регистрация пользователей Telegram-бота

## Цель
Создать первый рабочий модуль: /start, определение нового пользователя, данные Telegram, выбор роли, сохранение в БД.

На этом этапе НЕ делать: анкеты, поиск, чаты, оплату, встречи.

## Технологии
n8n · Telegram Bot API · Google Sheets (MVP) / PostgreSQL

## Таблица Пользователи
ID пользователя, ID Telegram, Имя, Фамилия, Ник, Пол (мужчина/женщина), Статус (активен/заблокирован), Дата регистрации, Последняя активность.

## Логика workflow
1. Telegram Trigger — новое сообщение = /start
2. Получить telegram_id, first_name, last_name, username
3. Проверка по telegram_id
4. Если найден → «С возвращением» + кнопки (заглушки)
5. Если новый → выбор роли 👨/👩
6. Запись в таблицу, защита от дублей

## Критерии готовности
✅ бот отвечает на /start  ✅ создаёт пользователя  ✅ сохраняет данные  ✅ не создаёт дубли  ✅ определяет пол
