# ТЗ №7 — Административная панель и модерация

## Цель
Проверка анкет, управление пользователями, жалобы, отзывы, блокировки, история, статистика.

## Роли
Пользователь · Модератор · Администратор

## Безопасность
Доступ по Telegram ID · проверка роли · журналирование.

## AI-помощник админа
Запросы вида «пользователи с большим числом жалоб».

## Критерии
✅ роли  ✅ проверка анкет  ✅ жалобы  ✅ блокировки  ✅ логи  ✅ статистика
