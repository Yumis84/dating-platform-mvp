# ТЗ №3 — Каталог анкет и просмотр профилей мужчинами

## Цель
Мужчина открывает каталог через Telegram WebApp: анкеты, фото, фильтры, избранное, переход к чату.

## Технологии
Telegram Bot API · WebApp · n8n · Google Sheets · file_id

## Логика
WebApp → n8n → активные анкеты (исключить blocked/deleted/свою) → JSON обратно.

## Фильтры
Город · Район · Цена · возраст · рост

## Избранное
Лист Избранное: user_id, profile_id, дата. Повторное добавление запрещено.

## Ограничения
НЕ: чат, сообщения, встречи, оплата, отзывы.

## Критерии
✅ каталог  ✅ фото  ✅ фильтры  ✅ избранное  ✅ без ошибок
