# ТЗ №4 — Анонимный чат

## Цель
Мужчина пишет девушке через сервис без раскрытия Telegram. Девушка получает и отвечает в Telegram. История сохраняется.

## Технологии
n8n · Telegram Bot API · WebApp · Google Sheets · Webhook · Telegram Trigger

## Таблицы
Чаты: chat_id, man_id, woman_id, status, created_at
Сообщения: message_id, chat_id, sender_id, text, created_at

## Определение чата при нескольких диалогах
Через chat_id / кнопки выбора диалога.

## Безопасность
Лимиты сообщений · антиспам · блок · жалобы · логирование.

## Критерии
✅ написать  ✅ анонимный чат  ✅ девушка получает  ✅ отвечает  ✅ история  ✅ контакты не раскрываются
