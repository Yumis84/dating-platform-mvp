# ТЗ №6 — Отзывы, рейтинг и репутация

## Цель
После подтверждённой встречи оценка друг друга. Репутация, доверие, защита от недобросовестного поведения.

Примечание: рассматривается переход от звёзд 1–5 к системе флагов безопасности (ok / no_show / scammer / inappropriate / other) — см. архитектурную оценку.

## Правила
Один отзыв на встречу с каждой стороны. Только после confirmed meeting. AI-проверка. Жалобы на отзыв.

## Отображение
Рейтинг / встречи / уровень доверия — без сырых флагов публично.

## Критерии
✅ запрос оценки  ✅ один отзыв  ✅ AI-проверка  ✅ пересчёт  ✅ отображение  ✅ жалобы админу
