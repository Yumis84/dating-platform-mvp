# ГЛАВНОЕ ТЗ — Архитектура платформы знакомств MVP v1.0

## 1. Описание проекта
Telegram-first платформа: анонимное общение, встречи, рейтинг/безопасность, автоматизация n8n.

## 2. Концепция
Платформа-посредник: безопасность, анонимность, меньше мошенничества, доверие, автоматизация.

## 3. Пользователи
Мужчина · Девушка · Администратор

## 4. Технологии
n8n · Telegram Bot/WebApp · Google Sheets → PostgreSQL · AI Agent

## 5. Архитектура
Пользователь → Telegram → Bot/WebApp → n8n → AI → БД → ответ

## 6. Модули 1–13
См. TZ_01 … TZ_13 в docs/tz/

## 7. Ключевые решения
Анонимность · chat_id · file_id · статусы анкет · подтверждение встреч · отзывы только после встречи

## 8–10. Правила, порядок, цель MVP
анализ → архитектура → согласование → реализация → тестирование
