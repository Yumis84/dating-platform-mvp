Содержание главного ТЗ (рекомендуемый минимум)
--------------------------------------------
1. Введение
   - Цель проекта
   - Ожидаемые пользователи и сценарии использования (user personas)
2. Обзор архитектуры (high-level)
   - Компоненты: Telegram Bot (entrypoint), Telegram WebApp (frontend), n8n (orchestrator / backend MVP), PostgreSQL (primary DB), Google Sheets (auxiliary storage for MVP), AI Agent
   - Схемы взаимодействия и sequence diagrams
3. Нефункциональные требования
   - Безопасность и минимизация PII
   - Масштабируемость
   - Производительность, SLA (если применимо)
4. Компоненты и их ответственность
   - Telegram Bot — прием команд/сообщений
   - n8n — регистрация, интеграции, workflow orchestration
   - PostgreSQL — первичные сущности и миграции
   - WebApp — Telegram WebApp frontend served via Nginx (static SPA in MVP)
   - AI Agent — рекомендации, модерация, генерация анкет
   - Google Sheets — облегчённая интеграция/импорт-экспорт для MVP
5. Развертывание и инфраструктура
   - Docker Compose для dev
   - Рекомендации по production (K8s, secrets manager, managed DB)
6. Безопасность и соответствие
   - Политика хранения секретов
   - Минимизация персональных данных
7. Миграции и управление схемой БД
   - Миграционный pipeline (инструменты и CI интеграция)
8. Контроль версий и workflow разработки
   - PR-процессы, review, ветвление
9. План по этапам (ссылка на ROADMAP и TZ_* документы)
10. Приложения
   - ER-диаграммы
   - Спецификации API
