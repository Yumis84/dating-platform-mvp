# ТЗ №5 — Система встреч, подтверждение, место и контакты

## Цель
Предложить встречу, указать дату/время/место/телефон, подтвердить, начать и завершить, история.

## Таблица Встречи
meeting_id, chat_id, man_id, woman_id, дата/время, город, район, тип/название/адрес, телефон, статусы, started_at, finished_at, duration.

## Телефон
Не в анкете. Только при создании встречи. Открывается после подтверждения. Привязан к встрече.

## История встреч
События: создание, подтверждение, отказ, начало, завершение, открытие контакта.

## Критерии
✅ предложить  ✅ место и телефон  ✅ скрытие адреса в частных местах  ✅ подтверждение  ✅ start/end  ✅ история  ✅ контакты по правилам
