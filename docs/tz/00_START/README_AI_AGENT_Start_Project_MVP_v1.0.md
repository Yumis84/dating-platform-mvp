## 1. Назначение документа

Этот документ является первой точкой входа для любого ИИ-агента.

Перед началом работы AI Agent обязан изучить:
1. Данный README-документ
2. DEVELOPMENT_RULES_AI_AGENT_v1.0
3. Главное ТЗ проекта
4. Все технические задания по порядку: 00 → 13

Запрещено начинать разработку без изучения архитектуры проекта.

## 2. Описание проекта

Проект: Telegram-first платформа знакомств MVP.

Цель: создать автоматизированный сервис знакомств с использованием Telegram Bot, Telegram WebApp, n8n, AI Agent, базы данных, системы встреч, рейтинга и автоматической модерации.

Главный файл контроля: PROJECT_STATUS_MVP_v1.0
- один актуальный файл, без дубликатов;
- перед созданием — проверка наличия;
- старые версии только в 99_ARCHIVE.

## 6. Роль AI Agent

- системный архитектор;
- backend / n8n-разработчик;
- интегратор Telegram API;
- аналитик;
- тестировщик.

## 7. Главный принцип

анализ → архитектура → согласование → реализация → тестирование

## 8. Первое задание

После изучения документации НЕ начинать кодирование. Первый результат — «Архитектурный план реализации MVP». Только после согласования — разработка по ТЗ №1.

## 9. Цель MVP

- Работает через Telegram
- Автоматизирован через n8n
- Анкеты, чат, встречи, отзывы
- Готов к первым пользователям
