# n8n workflows

## Inactive feature drafts

- `registration/WF_01_USER_REGISTRATION_MAN_WOMAN_DEV.json` — role-separated MAN/WOMAN routing and MAN context onboarding.
- `profile/WF_03_AI_PROFILE_AGENT.json` — valid WOMAN-only TZ #2 DEV draft.
- `catalog/WF_05_PROFILE_CATALOG_RANKING_DEV.json` — normalized-city hard filter plus optional preference ranking.

These JSON files have `active: false`, placeholder credentials, and have not been imported into live n8n.

Drop n8n workflow JSON templates into this folder to keep them under version control.
During development you can import them in the n8n UI or mount this folder into the n8n container
and use n8n CLI/API to import workflows automatically.
