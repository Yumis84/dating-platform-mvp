# Backups

Инструкции и политика резервных копий будут размещены здесь.

Ключевые идеи:
- Регулярные бэкапы PostgreSQL (pg_dump/pg_basebackup) с хранением в облаке.
- Экспорт критичных данных в Google Sheets для простого доступа в MVP (при необходимости).
- Резервные копии конфигураций n8n и экспорт workflows.
